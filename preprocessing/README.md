# Preprocessing, training and conversion

    run the following:

    pip install tensorflow pandas numpy tldextract scikit-learn matplotlib seaborn keras

    run preprocessing.ipynb notebook to process data, train the classifer and convert to inference-only TFLite model

Copy `model.tflite` and `word_index.json` into the app (see `../app/README.md`).

Tested with Python 3.12.9.
